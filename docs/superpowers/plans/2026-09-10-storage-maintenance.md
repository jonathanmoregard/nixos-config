> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (default) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add scheduled Nix maintenance and safely remove either merged or seven-day-inactive worktrees without deleting unmerged branches.

**Architecture:** Extend the existing fail-closed worktree sweeper rather than adding a second timer. Separate worktree eligibility from mandatory safety checks: exact-tip merged PR and seven-day commit age are alternative eligibility signals; clean state, approved root, lock state, and live-CWD checks always remain mandatory. Use standard NixOS `nix.gc` and `nix.optimise` options, covered by a fast evaluation contract.

**Tech Stack:** NixOS modules, Home Manager user units, Bash generated by `writeShellApplication`, Git, GitHub CLI, jq, Nix derivation test harnesses.

- [ ] **Step 2: Add two-phase Nix result-link validation/removal**

Add this helper before worktree processing:

```bash
remove_nix_result_links() {  # <worktree-path>
  local wt="$1" link target
  local -a links=()
  RESULT_LINKS_REMOVED=0
  REASON=""
  for link in "$wt/result" "$wt"/result-*; do
    [ -L "$link" ] || continue
    if ! target=$(readlink -- "$link" 2>/dev/null); then
      REASON="cannot read Nix result link $link — fail closed"
      return 1
    fi
    case "$target" in
      /nix/store/*) links+=("$link") ;;
      *)
        REASON="result-like symlink $link targets outside /nix/store — fail closed"
        return 1 ;;
    esac
  done
  for link in "''${links[@]}"; do
    if ! unlink -- "$link"; then
      REASON="cannot unlink verified Nix result link $link — fail closed"
      return 1
    fi
    RESULT_LINKS_REMOVED=$((RESULT_LINKS_REMOVED + 1))
  done
}
```

Call it only after root/protection/lock/presence/clean/live-CWD checks pass and immediately before non-force `git worktree remove`.

- [ ] **Step 3: Implement alternative eligibility signals**

In `process_worktree`, evaluate both predicates without short-circuiting safety:

```bash
local merged=0 aged=0 merged_reason age_reason
if check_merged "$branch"; then merged=1; else merged_reason="$REASON"; fi
if check_age "$branch"; then aged=1; else age_reason="$REASON"; fi
if [ "$merged" -eq 0 ] && [ "$aged" -eq 0 ]; then
  log "kept worktree $wt (branch $branch): not merged at local tip ($merged_reason); not inactive for $MAX_AGE_DAYS days ($age_reason)"
  return 0
fi
```

After successful worktree removal, delete the local branch only when `merged=1`. For age-only cleanup, log that the branch was preserved. For branches without worktrees, require only `check_merged` and delete exact-tip merged branches immediately; never delete branches using age alone.
